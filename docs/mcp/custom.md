# Произвольный MCP (`custom`)

Карточка-«конверт» для любого MCP-сервера, которого нет среди стандартных
видов. Ничего не разворачивает: сохраняет назначение и фрагмент подключения,
который попадёт в `.mcp.json`.

## Поля карточки

- **Наименование** — обязательное, для человека.
- **Назначение** — подсказка агенту и другим разработчикам.
- **Подключение** — JSON-фрагмент `"<имя>": { ... }`, вставляемый в `.mcp.json`
  как есть. По умолчанию:
  ```json
  "name": {
      "type": "http",
      "url": "http://localhost:8000/mcp"
  }
  ```

## Что вписать в «Подключение»

**HTTP (streamable) на этой или другой машине:**
```json
"my_mcp": {
    "type": "http",
    "url": "http://mcp.example.com:8000/mcp"
}
```

**SSE:**
```json
"my_mcp": {
    "type": "sse",
    "url": "http://mcp.example.com:8000/sse",
    "transport": "sse"
}
```

**stdio-команда** (запускается на машине агента при каждой сессии):
```json
"my_mcp": {
    "command": "npx",
    "args": ["-y", "@scope/my-mcp-server"],
    "env": { "MY_TOKEN": "..." }
}
```

Имя `my_mcp` — ключ в `.mcp.json`. Оно же подставляется в подсказки шаблона
окружения, если совпадает с плейсхолдером скилла.

## Развёртывание на отдельном сервере

Зависит от конкретного сервера — следуйте его документации. Общие требования:

- машина агента должна иметь TCP-доступ к серверу по нужному порту;
- для HTTP/SSE — стабильный URL (DNS-имя, при выходе за пределы доверенной
  сети — TLS/reverse-proxy);
- если у сервера нет своей аутентификации, поставьте перед ним reverse-proxy
  с авторизацией (токен/SSO) — MCP-серверы обычно не рассчитаны на публичный
  интернет;
- адрес в карточке — это адрес **с точки зрения машины агента**, а не сервера.

Для stdio-сервера на другой машине нужен обёрточный транспортный прокси
(например, `ssh user@host <команда>` в `command`/`args`) — «голый» stdio
поддерживается только локально.

## Проверка

```bash
# HTTP
curl -s -o /dev/null -w '%{http_code}\n' http://mcp.example.com:8000/mcp
# SSE обычно отвечает 200 и держит поток открытым
curl -s -N --max-time 2 http://mcp.example.com:8000/sse
```

Для stdio проверьте, что команда запускается в неинтерактивной оболочке и
пишет в stdout протокол MCP, а не отладочные сообщения.
