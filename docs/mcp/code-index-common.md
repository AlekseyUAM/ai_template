# code-index: общее ядро (два процесса, `daemon.toml`, alias)

Поддерживаемый способ развёртывания один — **нативный** (без Docker): бинарь
`bsl-indexer` (проект [Regsorm/code-index-mcp](https://github.com/Regsorm/code-index-mcp))
запускается прямо на хосте. Docker-вариант (`code-index.md`) —
**legacy**: в agentmon он больше не разворачивается.

Один сервис в каталоге `code_index_dir` обслуживает **несколько баз** — по
одному `[[paths]]` на базу; см. раздел «Один сервис — несколько баз».

## Два процесса

1. **Демон-индексатор** (`bsl-indexer daemon run`) — единственный писатель.
   Читает список путей из `daemon.toml`, строит и поддерживает индекс
   `<каталог кодовой базы>/.code-index/index.db` (пишет его **рядом с кодом**,
   поэтому каталог кодовой базы должен быть доступен на запись).
2. **MCP-сервер** (`bsl-indexer serve ...`) — read-only HTTP-клиент: отдаёт
   `/mcp`, читает тот же `index.db`. Сколько угодно клиентов могут подключаться
   к одному `serve`.

Оба процесса находят друг друга через `CODE_INDEX_HOME` — каталог с `daemon.toml`
и рантайм-файлом `daemon.json`. Если у них разные `CODE_INDEX_HOME`, сервер
отвечает `daemon_offline`, хотя демон жив.

## `daemon.toml`

```toml
[daemon]
http_host = "127.0.0.1"
http_port = 0          # 0 — автовыбор свободного порта (control-сервер демона)
log_level = "info"

[[paths]]
path = "/repos/src"    # в Docker — точка монтирования; локально — реальный путь
alias = "<имя проекта>"
language = "bsl"
```

- `path` — реальный абсолютный путь на хосте (`~` не раскрывается);
- `alias` — **имя проекта**;
- секции `[mcp]` (`mass_mode_tools`, в т.ч. `full_names` у `get_object_structure`)
  и `[[cache_targets]]` (URL `serve`, которому демон шлёт инвалидацию кэша)
  добавляет agentmon; `serve` читает `[mcp]` при старте — после правки нужен
  перезапуск `serve`.

## Один сервис — несколько баз

«Каталог code_index» (`code_index_dir`) — это **один сервис**: в нём лежит
бинарь `bsl-indexer`, общий `daemon.toml` и рантайм. К одной тому же сервису
подключают несколько карточек code-index, по одной на базу; все они пишут в
один `daemon.toml`.

- каждая база — отдельный блок `[[paths]]` (`alias` = имя проекта этой карточки,
  `path` = каталог выгрузки);
- повторное развёртывание с тем же `alias` обновляет `path` в существующем
  блоке, чужие блоки, комментарии и дополнительные ключи сохраняются;
- после правки agentmon вызывает `bsl-indexer daemon reload` (демон
  перечитывает `[[paths]]`) и **перезапускает `serve`** — алиасы и
  `[mcp]`/`[[cache_targets]]` сервер читает один раз при старте;
- порт сервиса хранится в `service.json` в том же каталоге
  (`{"port": <порт>, "version": 1}`). Все карточки сервиса должны указывать
  этот порт; развёртывание с другим портом отклоняется.

Если баз несколько, агент обязан передавать `repo="<имя проекта>"` явно —
по нему сервер выбирает базу.

## Алиас репозитория = имя проекта

Инструменты `code_index` принимают параметр `repo` — алиас репозитория. В этом
окружении **алиас всегда равен имени проекта**.

Три точки, которые обязаны совпадать побайтово:

1. **Имя проекта** (оно неизменяемо после создания; валидируется как
   Python-идентификатор — буквы/цифры/`_`, кириллица допускается).
2. **`daemon.toml`** — `alias = "<имя проекта>"`. При развёртывании из UI файл
   генерируется автоматически; при ручном развёртывании впишите имя проекта
   как есть.
3. **Скилл `mcp-usage`** (`template/.claude/skills/mcp-usage/SKILL.md`) — в
   подсказках агентам стоит плейсхолдер `{{CODE_INDEX_REPO}}`; при развёртывании
   окружения он заменяется на имя проекта (`agentmon.env.content.deploy_content`).

Чего **нельзя** делать:

- применять slug/транслитерацию/приведение регистра к одной из сторон — сервер
  сравнивает алиас точным строковым равенством;
- переименовывать проект в обход UI — алиас в `daemon.toml` и подсказках
  разъедется (пересоздайте `daemon.toml` и обновите окружение).

Агент должен передавать `repo="<имя проекта>"` в инструментах, где параметр
требуется (подробнее — скилл `mcp-usage`). Если в ответе `get_stats` или в тексте
ошибки виден **список** алиасов — репозиториев несколько: берите нужный из
списка. При одном репозитории вызов без `repo` технически проходит, но лучше
передавать явно.

## Проверка и диагностика

```bash
# демон жив и что индексирует
bsl-indexer daemon status --json
# или из агента: health / get_stats
curl -s -H 'Accept: text/event-stream' "http://127.0.0.1:<порт>/mcp"

# перечитать daemon.toml после правки
bsl-indexer daemon reload
```

Пока идёт первичная индексация, инструменты возвращают `{status, progress}`, а
не ошибку. `daemon_offline` означает, что `serve` не нашёл `daemon.json`:
проверьте, что демон запущен и оба процесса используют один `CODE_INDEX_HOME`.

## Хук-перенаправление (`code_index_guard.py`)

PreToolUse-хук (лежит в `hooks/` шаблона окружения) перенаправляет нативные
Read/Grep/Glob/Bash/PowerShell по индексированным каталогам в инструменты
`code_index`. Конфиг `.claude/hooks/code-index-guard.toml` генерируется при
развёртывании окружения; без него хук инертен и ничего не меняет. Откат —
удалить блок `PreToolUse` из `.claude/settings.json`; учтите, что обновление
окружения вписывает блок заново, а чтобы отключить гард насовсем, уберите
MCP code-index из проекта.

Параметр `max_denies` (по умолчанию 2) ограничивает число отказов подряд для
одного и того же вызова (session + tool + input). После исчерпания гард разрешает
нативный вызов, чтобы локальная модель не зациклилась на deny; счётчики хранятся
в `code-index-guard.state.json` рядом с конфигом и сбрасываются при смене сессии.
`max_denies = 0` возвращает прежнее поведение «не уступать никогда». Список прочих хуков —
в [template/README.md](../../template/README.md).

Гард несёт один `mcp_prefix`. Если в проекте несколько карточек code-index
(например, разные сервисы), а `.mcp.json` содержит их под одним ключом
(по умолчанию все дают `code_index`), выживает последний сервер — гард
защищает только его репозиторий. При разных именах — тоже только последний;
репозиторий остальных серверов не защищается (хук просто не вмешивается).
`catalog_dir` карточки должен быть абсолютным путём: `~` не раскрывается ни
хуком, ни демоном, и такой каталог отклоняется при развёртывании.
