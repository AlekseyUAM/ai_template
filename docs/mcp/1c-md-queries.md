# Метаданные + произвольные запросы — `1c-md-queries`

Тоже **расширение 1С** с HTTP-сервисом `mcp_APIBackend`, но с более широким
набором инструментов: помимо метаданных — произвольные запросы к данным и
сопутствующие операции (проверка запросов, навигационные ссылки, журнал
регистрации — состав зависит от версии расширения).

В поставке — `deps/mcp_tools_cfe/1c-mcp-tools-1.0.6.cfe`, сборка проекта
[SteelMorgan/1c-mcp-tools](https://github.com/SteelMorgan/1c-mcp-tools)
(код происходит от [vladimir-kharin/1c_mcp](https://github.com/vladimir-kharin/1c_mcp)
и [RooLee10/1c-mcp-tools](https://github.com/RooLee10/1c-mcp-tools)).

## Поля карточки

| Поле | Значение по умолчанию |
|---|---|
| Наименование | — (обязательно) |
| Имя в `.mcp.json` | `1c-md` |
| Назначение | «Произвольные запросы к данным, вся информация об актуальных метаданных конфигурации» |
| URL | `localhost` — хост веб-публикации |
| Имя базы | `my_database` — имя публикации |
| Подключение | строится автоматически |

```json
"1c-md": {
    "type": "http",
    "url": "http://localhost/my_database/hs/mcp"
}
```

Кнопка **«Скачать cfe»** отдаёт `1c-mcp-tools-1.0.6.cfe`.

## Развёртывание

Шаги те же, что у вида «Метаданные» (см. [1c-md.md](1c-md.md)):

1. Скачать `.cfe` кнопкой в карточке (или взять из `deps/mcp_tools_cfe/`).
2. Загрузить расширение в информационную базу (Конфигуратор → «Расширения
   конфигурации» → «Добавить из файла» → «Применить»).
3. Опубликовать базу на веб-сервере так, чтобы был доступен HTTP-сервис
   `mcp_APIBackend`: `http://<хост>/<публикация>/hs/mcp/`.
   Имя публикации в URL **чувствительно к регистру**.
4. Настроить доступ: прямое подключение требует публикации без аутентификации
   (только доверенная сеть); иначе — Python-прокси/адаптер из проекта
   расширения (в апстриме у расширения есть HTTP-путь `/hs/mcp/rpc` и прокси;
   детали — в README соответствующего проекта).
5. Заполнить карточку (`URL`, `Имя базы`).

## Развёртывание на отдельном сервере

Расширение и публикация — на сервере 1С; на машине агента ничего не нужно.
В карточке укажите адрес этого сервера и имя публикации. Через прокси —
адрес прокси в поле «Подключение».

Учтите: инструменты произвольных запросов выполняют запросы **от имени
пользователя, под которым работает HTTP-сервис**. Не публикуйте такой сервис
без аутентификации в недоверенной сети и не давайте ему лишних прав в базе.

## Проверка

```bash
curl -i "http://<хост>/<публикация>/hs/mcp/"
```

Из агента — запрос списка объектов метаданных и простой запрос к данным
(например, количество элементов справочника).
