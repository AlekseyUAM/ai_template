# P1.5 — Стартовая страница + дерево «Проекты и задачи» — дизайн

Дата: 2026-10-04. Статус: утверждён (Фаза 1).

## Контекст
Новая стартовая страница по `tmp/NOTE.md`: заголовок «Agent Monitor v.{версия}»,
верхнее меню — справочники (Проекты, Задачи, MCP), две панели: «Проекты и задачи» и
«Выполнение». Ничего лишнего. P1.5 делает стартовую страницу + панель «Проекты и
задачи» (дерево) + данные для неё. Панель «Выполнение» (стеки) — P1.6 (пока плейсхолдер).

## Панель «Проекты и задачи»
- 2 кнопки сверху: «Создать проект» (→ `/project-wizard`), «Создать задачу» (→ `/task-wizard`).
- Дерево: верхний уровень — проект (имя + путь); второй уровень — задачи: крестик
  удаления, название, путь к задаче, время выполнения (мин), статус, этап.
- Статусы задачи: запланирована, в очереди, выполняется, остановлена, ожидает
  пользователя (из overall_status; маппинг на русские подписи).

## API
- `GET /api/env/tree` → `{version, projects:[{id, name, path, tasks:[{id, name,
  task_path, elapsed_min, status, stage}]}]}`. Агрегирует ProjectRepo + TaskRepo;
  `elapsed_min` = (finished_at|now − started_at)/60, 0 если не стартовала; `task_path`
  = `<project.path>/tasks/task#<id>`; `status` — русская подпись по overall/статусу.
- Удаление задачи — существующий `DELETE /api/env/tasks/{id}` (P1.4).
- Версия — `GET /api/env/version` (есть).

## Web
- `/` — новая стартовая: header «Agent Monitor v{version}», верхнее меню (Проекты →
  `/projects`, Задачи → `/task-wizard`, MCP → `/mcp`), панель «Проекты и задачи»
  (дерево из `/api/env/tree`, кнопки создания, удаление задачи) и панель «Выполнение»
  (плейсхолдер «стеки — P1.6»). Тёмная тема. Автообновление дерева (polling).
- Старый монитор agentmon (сессии/очередь) переносится на `/agents` (route +
  переименовать текущий `index.html` контент), чтобы `/` стал новой стартовой.
