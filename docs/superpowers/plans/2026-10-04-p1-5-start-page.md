## Task 1: API дерева (tree_api.py)
**Interfaces:** `build_tree_router(store, now_fn=time.time) -> APIRouter`; create_app подключает.
- `GET /api/env/tree` → `{version: current_env_version(), projects:[{id,name,path, tasks:[{id,name,task_path,elapsed_min,status,stage}]}]}`.
  - tasks из TaskRepo.list(project_id); `task_path = f"{project['path']}/tasks/task#{task['id']}"`; `elapsed_min = round((((finished_at or now) - started_at)/60), 1) if started_at else 0`; `status` — русская подпись по полю `status` задачи (planned→«запланирована», queued→«в очереди», running→«выполняется», stopped→«остановлена», awaiting_user→«ожидает пользователя», done→«выполнена», failed→«ошибка»); `stage` — поле stage.
- 503 если store None.
