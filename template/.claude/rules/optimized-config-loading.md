# Оптимизированная загрузка конфигурации

Скрипт `.claude/tools/load-config-optimized.py` загружает в ИБ только изменённые
файлы конфигурации (`1c-batch load-config src/cf --list-file …`) вместо полной
перезагрузки. Кроссплатформенный; требует Python 3.6+, git и локальную копию
`1c-batch` (wrapper `.claude/skills/1c-batch/scripts/1c-batch.py`).

## Использование

```bash
# Загрузить только изменённые файлы (git diff относительно HEAD по src/cf)
python .claude/tools/load-config-optimized.py

# Полная загрузка
python .claude/tools/load-config-optimized.py --full
```

Скрипт берёт изменённые файлы из `git diff`, убирает префикс `src/cf/` (пути в
list-file задаются относительно каталога `src/cf`) и запускает загрузку. Если
изменённых файлов нет — загрузка пропускается.

## Когда нужна полная загрузка

Частичная загрузка не проверяет зависимости между объектами. Используй `--full`:
- структурные/системные изменения (подсистемы, переименование объектов);
- контрольная проверка синхронизации БД и исходников;
- при сомнениях в консистентности.

Выигрыш во времени тем больше, чем меньше доля изменённых файлов; на «холодном»
старте разница заметна, на «тёплой» базе — минимальна.
