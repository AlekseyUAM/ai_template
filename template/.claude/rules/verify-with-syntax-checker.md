# Проверка статическим анализом

После каждого изменения BSL-кода прогоняй статический анализ через MCP `bsl_ls`
(инструмент `mcp__bsl_ls__check`, с `config` из `.bsl-language-server.json`) и устраняй
найденные ошибки до перехода к следующему шагу. Не вызывай бинарь
`bsl-language-server` напрямую. Не считай задачу готовой, пока статанализ не чист.

Перед вызовом вычисли sha256 файла (`sha256sum <файл>` или
`shasum -a 256 <файл>`) и передай его в `check`. Без `sha256` инструмент
отклонит вызов. Не перепечатывай модуль вручную.

**BOM:** сервер сам срезает ведущий UTF-8 BOM перед анализом (BSL LS падает на
нём с `ParseError`). Принимается `sha256` как файла с BOM (`sha256sum`), так и
нормализованного текста без BOM — срезать BOM вручную не обязательно.
