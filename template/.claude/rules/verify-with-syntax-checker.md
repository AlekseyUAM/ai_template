# Проверка статическим анализом

После каждого изменения BSL-кода прогоняй статический анализ через MCP `bsl_ls`
(инструмент `mcp__bsl_ls__check`, с `config` из `.bsl-language-server.json`) и устраняй
найденные ошибки до перехода к следующему шагу. Не вызывай бинарь
`bsl-language-server` напрямую. Не считай задачу готовой, пока статанализ не чист.
