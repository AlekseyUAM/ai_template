# Запуск юнит-тестов

Команда вида **«запусти тесты <конфиг>»** (например, «запусти тесты configs/test.json»)
выполняется скриптом `.claude/tools/run-tests.py`:

```bash
python .claude/tools/run-tests.py configs/test.json
```

Скрипт стартует базу (из `.1c-devbase.json`) в режиме предприятия через
`1c-batch run-enterprise -C "ВыполнитьЗапускЮнитТестов=<абсолютный путь к конфигу>"`.
Относительный путь к конфигу приводится к абсолютному; если файл не найден —
запуск не делается, если пуст — выводится предупреждение.

Без аргумента используется `configs/test.json` по умолчанию. Кроссплатформенно;
требует Python 3.6+ и локальную копию `1c-batch`
(wrapper `.claude/skills/1c-batch/scripts/1c-batch.py`).

Результаты прогона пишет сам обработчик тестов в конфигурации (не stdout/лог
платформы) — смотри туда, куда он их складывает.
