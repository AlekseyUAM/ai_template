# Каталог: ОбщегоНазначения (и клиент-серверные варианты)

Публичный API модулей `ОбщегоНазначения` (сервер), `ОбщегоНазначенияКлиентСервер`
(везде), `ОбщегоНазначенияКлиент` (клиент). Формат записи:

> **`Функция(Параметры)`** — назначение.
> 🚲 — что разработчик обычно пишет вручную вместо этого.

Контекст указан в заголовке подраздела. `⚠ устар.` — не рекомендовать, дана замена.
Самый частый источник «велосипедов» — реквизиты объектов и коллекции.

---

## Реквизиты объектов — `ОбщегоНазначения` (сервер)

Главная тема. Чтение реквизита через `Ссылка.Реквизит` делает неявный запрос;
в цикле — N запросов. БСП читает одним запросом и учитывает права.

- **`ЗначениеРеквизитаОбъекта(Ссылка, ИмяРеквизита, ВыбратьРазрешенные = Ложь)`** — значение одного реквизита по ссылке, одним запросом.
  🚲 Свой `Запрос` за одним полем; `Ссылка.Реквизит` в тяжёлом коде; helper `ПолучитьРеквизит`.
- **`ЗначенияРеквизитовОбъекта(Ссылка, Реквизиты, ВыбратьРазрешенные = Ложь)`** — структура значений нескольких реквизитов одной ссылки (`Реквизиты` — строка «Склад,Организация» или массив/структура).
  🚲 Несколько обращений `Ссылка.А`, `Ссылка.Б` подряд; запрос за парой полей.
- **`ЗначенияРеквизитовОбъектов(Ссылки, Реквизиты, ВыбратьРазрешенные = Ложь)`** — соответствие «ссылка → структура значений» для набора ссылок, **одним запросом**.
  🚲 Цикл `Для Каждого Ссылка Из Массив … Ссылка.Реквизит` (N запросов к СУБД).
- **`ЗначениеРеквизитаОбъектов(МассивСсылок, ИмяРеквизита, ВыбратьРазрешенные = Ложь)`** — соответствие «ссылка → значение одного реквизита» для набора ссылок.
  🚲 Тот же цикл ради одного поля.
- **`УстановитьЗначениеРеквизита(Объект, ИмяРеквизита, Значение)`** / **`УстановитьЗначенияРеквизитов(Объект, Значения)`** — безопасно заполнить реквизит(ы), с проверкой существования.
- **`ЕстьРеквизитОбъекта(ИмяРеквизита, МетаданныеОбъекта)`** — есть ли реквизит с таким именем.
  🚲 Свой перебор `МетаданныеОбъекта.Реквизиты`.

### `ОбщегоНазначенияКлиентСервер`
- **`ЕстьРеквизитИлиСвойствоОбъекта(Объект, ИмяРеквизита)`** — есть ли реквизит/свойство у произвольного объекта без обращения к метаданным.
  🚲 `Попытка … Объект[Имя] … Исключение` ради проверки наличия.

## Предопределённые, проведение, ссылки — `ОбщегоНазначения`

- **`ПредопределенныйЭлемент(ПолноеИмяПредопределенного)`** — ссылка предопределённого по полному имени («Справочник.Валюты.Рубль»), в т.ч. там, где прямое обращение недоступно.
  🚲 Запрос за предопределённым; хранение его ссылки руками.
- **`ЭтоПредопределенныеЭлементы(Элементы)`** — признак предопределённости (с учётом прав).
- **`ПроверитьПроведенностьДокументов(Документы)`** — возвращает непроведённые из списка.
  🚲 Цикл с проверкой `Докумен.Проведен`.
- **`ПровестиДокументы(Документы)`** — попытка провести, возвращает несумевшие.
- **`ЕстьСсылкиНаОбъект(СсылкаИлиМассив, ИскатьСредиСлужебных = Ложь)`** — есть ли ссылки на объект в базе.
  🚲 Свой поиск мест использования запросами.
- **`ЗаменитьСсылки(ПарыЗамен, ПараметрыЗамены = Неопределено)`** — замена ссылок во всех данных.
- **`МестаИспользования(НаборСсылок, АдресРезультата = "")`** — все места использования ссылок.
- **`ИмяЗначенияПеречисления(Значение)`** — имя значения перечисления по ссылке.

## Коллекции: массивы, структуры, соответствия — `ОбщегоНазначенияКлиентСервер`

Доступны и на клиенте, и на сервере.

- **`ЗначениеВМассиве(Значение)`** — массив из одного значения.
  🚲 `М = Новый Массив; М.Добавить(Знач);` — три строки ради одного элемента (частый велосипед при передаче отбора).
- **`СвернутьМассив(Массив)`** — копия массива с уникальными значениями.
  🚲 Удаление дублей циклом через вложенный поиск / через соответствие.
- **`РазностьМассивов(Массив, МассивВычитания)`** — элементы первого, которых нет во втором.
  🚲 Двойной цикл с `Найти`.
- **`ДополнитьМассив(Приемник, Источник, ТолькоУникальные = Ложь)`** — добавить все элементы массива.
  🚲 Цикл `Для Каждого … Приемник.Добавить`.
- **`УдалитьЗначениеИзМассива(Массив, Значение)`** / **`УдалитьВсеВхожденияЗначенияИзМассива(Массив, Значение)`** / **`УдалитьВсеВхожденияТипаИзМассива(Массив, Тип)`** — удаление элементов.
  🚲 Обратный цикл по индексам с `Удалить`.
- **`СвойствоСтруктуры(Структура, Ключ, ЗначениеПоУмолчанию = Неопределено)`** — значение свойства или значение по умолчанию.
  🚲 `Если Структура.Свойство("К") Тогда Знач = Структура.К Иначе Знач = …`.
- **`ДополнитьСтруктуру(Приемник, Источник, Заменять = Неопределено)`** / **`ДополнитьСоответствие(Приемник, Источник, Заменять)`** — слияние.
  🚲 Цикл `Для Каждого КлючЗначение Из Источник`.
- **`КлючиСтруктурыВСтроку(Структура, Разделитель = ",")`** — строка ключей.
  🚲 Цикл со склейкой ключей.
- **`СпискиЗначенийИдентичны(Список1, Список2)`** — сравнение списков значений/массивов по значениям.
- **`ДополнитьСписок(СписокПриемник, СписокИсточник, ...)`** — слияние списков значений.

### Таблицы значений — `ОбщегоНазначения` (сервер)
- **`ВыгрузитьКолонку(КоллекцияСтрок, ИмяКолонки, ТолькоУникальные = Ложь)`** — массив значений колонки.
  🚲 Цикл по строкам ТЗ со сбором значений в массив.
- **`ТаблицаЗначенийВМассив(ТаблицаЗначений)`** — массив структур (для передачи ТЗ на клиент).
  🚲 Ручная перекладка строк в массив структур.
- **`СтрокаТаблицыЗначенийВСтруктуру(СтрокаТЗ)`** — строка ТЗ → структура по колонкам.
- **`КоллекцииИдентичны(К1, К2, ИменаКолонок = "", ...)`** — сравнение ТЗ/дерева построчно.
  🚲 Свой построчный сравнивающий цикл.
- **`СтруктураПоМенеджеруЗаписи(МенеджерЗаписи, МетаданныеРегистра)`** — измерения/ресурсы/реквизиты набора в структуру.

### `ОбщегоНазначенияКлиентСервер` — таблицы (без типов, недоступных на клиенте)
- **`ДополнитьТаблицу(ТаблицаИсточник, ТаблицаПриемник)`** — скопировать строки одной ТЗ в другую.
  🚲 Цикл с `ЗаполнитьЗначенияСвойств` по строкам.
- **`ДополнитьТаблицуИзМассива(Таблица, Массив, ИмяПоля)`** — строки ТЗ из массива значений.

## Копирование и сравнение данных

### `ОбщегоНазначения` (сервер) и `ОбщегоНазначенияКлиент` (клиент)
- **`СкопироватьРекурсивно(Источник, ФиксироватьДанные = Неопределено)`** — полная копия структуры/соответствия/массива/списка/ТЗ с учётом вложенности.
  🚲 Ручной обход с пересозданием коллекций; устаревшие `СкопироватьСтруктуру`/`СкопироватьМассив`.
- **`ОбщегоНазначения.ДанныеСовпадают(Данные1, Данные2)`** — сравнение данных сложной структуры с вложенностью.
  🚲 Свой рекурсивный компаратор.
- **`ОбщегоНазначения.ФиксированныеДанные(Данные, ВызыватьИсключение = Истина)`** — рекурсивная фиксация структуры/соответствия/массива.
- **`ОбщегоНазначения.КонтрольнаяСуммаСтрокой(Данные, Алгоритм = Неопределено)`** — контрольная сумма произвольных данных.
  🚲 Свой хэш через `ХешированиеДанных` с сериализацией.

> ⚠ устар. в `ОбщегоНазначенияКлиентСервер`: `СкопироватьСтруктуру`,
> `СкопироватьСоответствие`, `СкопироватьМассив`, `СкопироватьСписокЗначений`,
> `СкопироватьРекурсивно` → использовать `СкопироватьРекурсивно` из
> `ОбщегоНазначения`/`ОбщегоНазначенияКлиент`. `СократитьМассив` → `РазностьМассивов`.

## Типы и метаданные — `ОбщегоНазначения` (сервер)

Определение вида объекта по имени метаданных — классический антипаттерн
(ловится `code-analyze: type-check-via-metadata-name`).

- **`ЭтоДокумент / ЭтоСправочник / ЭтоПеречисление / ЭтоПланОбмена / ЭтоПланВидовХарактеристик / ЭтоПланСчетов / ЭтоПланВидовРасчета / ЭтоБизнесПроцесс / ЭтоЗадача / ЭтоРегистрСведений / ЭтоРегистрНакопления / ЭтоРегистрБухгалтерии / ЭтоРегистрРасчета / ЭтоКонстанта / ЭтоЖурналДокументов / ЭтоПоследовательность / ЭтоРегламентноеЗадание / ЭтоРегистр(ОбъектМетаданных)`** — принадлежность к общему типу.
  🚲 `Строка(ТипЗнч(…))` разбором; `Метаданные().Имя`, `ПолноеИмя()` с `СтрНачинаетсяС`.
- **`ЭтоОбъектСсылочногоТипа(ОписаниеОбъекта)`** — ссылочный ли объект метаданных.
- **`ЭтоСсылка(ПроверяемыйТип)`** — ссылочный ли тип.
- **`ЗначениеСсылочногоТипа(Значение)`** — ссылочного ли типа значение.
- **`СсылкаСуществует(ПроверяемаяСсылка)`** — есть ли запись в базе по ссылке (бито́е).
  🚲 Запрос `ВЫБРАТЬ … ГДЕ Ссылка = &Ссылка` для проверки существования.
- **`ОбъектЯвляетсяГруппой(Объект)`** — группа ли элемента справочника/ПВХ.
- **`ИмяТаблицыПоСсылке(Ссылка)`** / **`ВидОбъектаПоСсылке(Ссылка)`** / **`ВидОбъектаПоТипу(ТипОбъекта)`** — полное имя / имя вида.
  🚲 Разбор `Метаданные().ПолноеИмя()` строковыми функциями.
- **`ОбъектМетаданныхПоПолномуИмени(ПолноеИмя)`** — быстрый аналог `Метаданные.НайтиПоПолномуИмени`.
- **`МенеджерОбъектаПоПолномуИмени(ПолноеИмя)`** / **`МенеджерОбъектаПоСсылке(Ссылка)`** — менеджер объекта.
  🚲 Длинный `Если … Документы[Имя] … ИначеЕсли Справочники[Имя]`.
- **`СтроковоеПредставлениеТипа(Тип)`** — «СправочникСсылка.Имя» по типу.
- **`ИдентификаторОбъектаМетаданных(…)`** / **`ОбъектМетаданныхПоИдентификатору(…)`** — ссылка-идентификатор объекта метаданных для хранения в базе и обратно.
- **`ПредставлениеОбъекта(ОбъектМетаданных)`** / **`ПредставлениеСписка(ОбъектМетаданных)`** — синоним/представление из свойств метаданных.
- **`ОписаниеТипаСтрока(ДлинаСтроки)` / `ОписаниеТипаЧисло(...)` / `ОписаниеТипаДата(ЧастиДаты)` / `ОписаниеТипаВсеСсылки()`** — конструкторы `ОписаниеТипов`.
  🚲 Ручное создание `Новый ОписаниеТипов` с массивом типов и квалификаторами.
- **`ОписаниеТипаСостоитИзТипа(ОписаниеТипа, ТипЗначения)`** — состоит ли описание из единственного типа.
- **`ИменаРеквизитовПоТипу(Ссылка, Тип)`** — реквизиты объекта заданного типа.

## Окружение, конфигурация — `ОбщегоНазначения` (сервер) / `ОбщегоНазначенияКлиент`

- **`ИнформационнаяБазаФайловая()`** — файловый ли режим ИБ.
  🚲 Разбор строки соединения `СтрСоединенияИБ()` руками.
- **`ЭтоWindowsКлиент() / ЭтоWindowsСервер() / ЭтоLinuxКлиент() / ЭтоLinuxСервер() / ЭтоMacOSКлиент() / ЭтоВебКлиент() / ЭтоМобильныйКлиент()`** — определение ОС/клиента.
  🚲 Разбор `СистемнаяИнформация().ТипПлатформы`.
- **`КлиентПодключенЧерезВебСервер()`**, **`РежимОтладки()`**, **`РаспределеннаяИнформационнаяБаза()`**, **`ЭтоПодчиненныйУзелРИБ()`**, **`РазделениеВключено()`**, **`ДоступноИспользованиеРазделенныхДанных()`** — признаки среды.
- **`РедакцияКонфигурации()`** — редакция («1.2» из «1.2.3.4»).
- **`ПодсистемаСуществует(ПолноеИмяПодсистемы)`** + **`ОбщийМодуль(Имя)`** — условный вызов необязательной подсистемы.
  🚲 `Попытка Выполнить("ОбщийМодуль.Метод()") Исключение` ради «мягкой» зависимости.
- `ОбщегоНазначенияКлиент`: **`ДатаСеанса()`** — текущая дата в часовом поясе сеанса (вместо `ТекущаяДата()` на клиенте), **`ДатаУниверсальная()`**.

> ⚠ устар.: многие такие функции есть и в `ОбщегоНазначенияКлиентСервер`, но
> помечены устаревшими — бери из `ОбщегоНазначения`/`ОбщегоНазначенияКлиент`.

## Файлы, пути, email, версии, URI — `ОбщегоНазначенияКлиентСервер`

Работа со **строковым** путём (не с файловой системой — та в `ФайловаяСистема`).

- **`ДобавитьКонечныйРазделительПути(ПутьКаталога)`** — добавить `\`/`/`, если нет.
  🚲 `Если Прав(Путь,1) <> "\" Тогда Путь = Путь + "\"`.
- **`ПолучитьПолноеИмяФайла(ИмяКаталога, ИмяФайла)`** — склейка каталога и имени.
- **`РазложитьПолноеИмяФайла(ПолноеИмяФайла, ЭтоКаталог = Ложь)`** — структура: путь, имя, расширение, базовое имя.
  🚲 Свой разбор пути через `СтрНайти`/`Сред` по `\` и `.`.
- **`ПолучитьРасширениеИмениФайла(ИмяФайла)`** / **`РасширениеБезТочки(Расширение)`** / **`ПолучитьИмяСРасширением(Имя, Расширение)`** — работа с расширением.
- **`НайтиНедопустимыеСимволыВИмениФайла(ИмяФайла)`** / **`ЗаменитьНедопустимыеСимволыВИмениФайла(ИмяФайла, НаЧтоМенять)`** / **`ПолучитьНедопустимыеСимволыВИмениФайла()`** — валидация имени файла.
  🚲 Свой список запрещённых символов и замена.
- **`СтруктураURI(СтрокаURI)`** — разбор URI на части (схема, хост, порт, путь…).
  🚲 Ручной парсинг URL строковыми функциями.
- **`АдресЭлектроннойПочтыСоответствуетТребованиям(Адрес, РазрешитьЛокальные = Ложь)`** — проверка email по RFC.
  🚲 Свой регэксп/проверка «@ и точка».
- **`АдресаЭлектроннойПочтыИзСтроки(СписокАдресов)`** / **`РазобратьСтрокуСПочтовымиАдресами(Адреса)`** — разбор строки адресов.
- **`СравнитьВерсии(Версия1, Версия2)`** / **`СравнитьВерсииБезНомераСборки(...)`** / **`ВерсияКонфигурацииБезНомераСборки(Версия)`** — сравнение версий «1.2.3.4».
  🚲 Свой разбор версии на части и поэлементное сравнение.
- **`ЗаменитьНедопустимыеСимволыXML(Текст, СимволЗамены)`** / **`УдалитьНедопустимыеСимволыXML(Текст)`** — чистка строки для XML.
- **`ПустойУникальныйИдентификатор()`** — пустой UUID.

## Формы, отборы, динамические списки — `ОбщегоНазначенияКлиентСервер`

- **`ПолучитьРеквизитФормыПоПути(Форма, ПутьРеквизита)`** / **`УстановитьРеквизитФормыПоПути(Форма, Путь, Значение, ...)`** — доступ к реквизиту формы по строковому пути.
- **`УстановитьЭлементОтбора(ОбластьПоискаДобавления, ИмяПоля, ПравоеЗначение, ВидСравнения, ...)`** — добавить/заменить элемент отбора.
  🚲 Ручное создание `ЭлементОтбора`, поиск существующего, установка свойств.
- **`УстановитьЭлементОтбораДинамическогоСписка(ДинамическийСписок, ИмяПоля, ПравоеЗначение, ...)`** / **`УдалитьЭлементыГруппыОтбораДинамическогоСписка(...)`** — отбор динамического списка.
- **`УстановитьПараметрДинамическогоСписка(Список, ИмяПараметра, Значение, Использование = Истина)`** — параметр динамического списка.
- **`НайтиЭлементыИГруппыОтбора(...)`** / **`СоздатьГруппуЭлементовОтбора(...)`** / **`ИзменитьЭлементыОтбора(...)`** / **`УдалитьЭлементыГруппыОтбора(...)`** — работа с деревом отбора КД.
- **`УстановитьСвойствоЭлементаФормы(ЭлементыФормы, ИмяЭлемента, ИмяСвойства, Значение)`** / **`ЗначениеСвойстваЭлементаФормы(...)`** — безопасно, когда элемента может не быть на форме.
- `ОбщегоНазначения` (сервер): **`СтруктураСвойствДинамическогоСписка()`** + **`УстановитьСвойстваДинамическогоСписка(Список, СвойстваСписка)`** — текст запроса/основная таблица/динамическое считывание за один вызов.

## Самодиагностика и сообщения — `ОбщегоНазначенияКлиентСервер`

- **`Проверить(Условие, Сообщение = "", КонтекстПроверки = "")`** — исключение, если условие ложно.
  🚲 `Если НЕ Условие Тогда ВызватьИсключение …`.
- **`ПроверитьПараметр(ИмяМетода, ИмяПараметра, Значение, ОжидаемыеТипы, ...)`** — проверка типа параметра.
  🚲 Свой `Если ТипЗнч(П) <> Тип(…) Тогда ВызватьИсключение`.
- **`ДобавитьОшибкуПользователю(Ошибки, ПолеОшибки, Текст, ...)`** + **`СообщитьОшибкиПользователю(Ошибки, Отказ)`** — накопление и вывод однотипных ошибок.
- **`ТекстОшибкиЗаполнения(...)`**, **`ПутьКТабличнойЧасти(ИмяТЧ, НомерСтроки, ИмяРеквизита)`** — тексты/пути для сообщений в форме.
- `ОбщегоНазначения`/`ОбщегоНазначенияКлиент`: **`СообщитьПользователю(Текст, КлючДанных, Поле, ПутьКДанным, Отказ)`** — сообщение, привязанное к данным/полю формы.
  🚲 Голый `Сообщить(…)` без привязки к данным.

## Выполнение кода, настройки, разное — `ОбщегоНазначения` (сервер)

- **`ВыполнитьВБезопасномРежиме(Алгоритм, Параметры)`** / **`ВычислитьВБезопасномРежиме(Выражение, Параметры)`** — `Выполнить`/`Вычислить` с безопасным режимом и профилем безопасности.
  🚲 Прямой `Выполнить(Текст)` / `Вычислить(Текст)` без безопасного режима.
- **`ВыполнитьМетодКонфигурации(ИмяМетода, Параметры, ЭтоФункция)`** / **`ВыполнитьМетодОбъекта(Объект, ИмяМетода, ...)`** — вызов метода по имени с учётом профилей безопасности.
- **`ХранилищеОбщихНастроекСохранить/Загрузить/Удалить(...)`**, аналогично `ХранилищеСистемныхНастроек*`, `ХранилищеНастроекДанныхФорм*` — работа с хранилищами настроек с поддержкой длинных ключей и разделения.
  🚲 Прямое `ХранилищеОбщихНастроек.Сохранить(...)` без обрезки длинных ключей.
- **`ЗаписатьДанныеВБезопасноеХранилище(Владелец, Данные, Ключ)`** / **`ПрочитатьДанныеИзБезопасногоХранилища(Владелец, Ключи, ...)`** / **`УдалитьДанныеИзБезопасногоХранилища(...)`** — конфиденциальные данные (пароли).
  🚲 Хранение паролей в реквизитах/константах.
- **`ПодключитьКомпонентуИзМакета(Идентификатор, ПолноеИмяМакета, ...)`** — внешняя компонента из макета-ZIP.
- **`СкопироватьСтрокиВБуферОбмена(ТЧ, ВыделенныеСтроки)`** / **`СтрокиИзБуфераОбмена()`** / **`ПустойБуферОбмена()`** — внутренний буфер обмена строк ТЧ.
- **`РаспределитьСуммуПропорциональноКоэффициентам`** — см. раздел арифметики.
