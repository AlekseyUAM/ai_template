# Каталог: остальные группы модулей БСП

Публичный API 15 групп (кроме `ОбщегоНазначения*` — см. `obshego.md`). Формат:

> **`Модуль.Функция(Параметры)`** — назначение.
> 🚲 — что пишут вручную вместо этого.

`⚠ устар.` — не рекомендовать, дана замена. Напоминание: функции тем «Файлы»,
«Контактная информация», «Банки», «Курсы валют», «Оценка производительности»
доступны только при внедрённой соответствующей подсистеме.

---

## Строки — `СтроковыеФункцииКлиентСервер` (везде)

Крупнейший источник «велосипедов» после реквизитов объектов.

- Разбиение строки по разделителю → **платформенная `СтрРазделить(Строка, Разделитель, ПропускатьПустые)`**, а не БСП.
  🚲 Свой разбор через `СтрНайти` + `Сред` в цикле. ❌ Не рекомендуй `СтроковыеФункцииКлиентСервер.РазложитьСтрокуВМассивПодстрок` — это обёртка над платформой; на поддерживаемых версиях бери `СтрРазделить` напрямую.
- **`РазложитьСтрокуВМассивСлов(Значение, РазделителиСлов = Неопределено)`** — разбиение на слова по набору разделителей (разделитель — любой из набора символов; у платформы прямого аналога нет).
- Подстановка параметров в шаблон → **платформенная `СтрШаблон(Шаблон, Пар1…Пар10)`** (`%1…%N`), а не БСП.
  🚲 Конкатенация `"Текст " + Знач1 + " из " + Знач2`; ручная замена `%1`. ❌ Не рекомендуй `СтроковыеФункцииКлиентСервер.ПодставитьПараметрыВСтроку` / `ПодставитьПараметрыВСтрокуИзМассива` — это обёртки над платформой; бери `СтрШаблон` напрямую.
- **`ВставитьПараметрыВСтроку(Шаблон, Параметры)`** — замена именованных `[Параметр]` на значения.
- **`ПараметрыИзСтроки(СтрокаПараметров, Разделитель = ";")`** — разбор «ключ=значение;…» в соответствие.
- **`СформироватьСтрокуСимволов(Символ, ДлинаСтроки)`** — строка из повторяющегося символа.
  🚲 Цикл с конкатенацией символа.
- **`ДополнитьСтроку(Значение, ДлинаСтроки, Символ = "0", Режим = "Слева")`** — дополнение до длины (ведущие нули).
  🚲 Цикл добавления нулей слева.
- **`УдалитьПовторяющиесяСимволы(Значение, УдаляемыйСимвол, Режим = "Слева")`** — срезать крайние повторы.
- **`СократитьДвойныеКавычки(Значение)`** — убрать обрамляющие `"`.
- **`УдалитьПоследнийСимволВСтроке(Текст, ЧислоСимволов = 1)`** — срезать N символов справа.
  🚲 `Лев(Текст, СтрДлина(Текст) - 1)`.
- **`ТолькоЦифрыВСтроке(Значение, ...)`** / **`ТолькоЛатиницаВСтроке(...)`** / **`ТолькоСимволыНациональногоАлфавитаВСтроке(...)`** — проверки состава строки.
  🚲 Посимвольный цикл с проверкой кода символа.
- **`ЭтоУникальныйИдентификатор(Значение)`** — похожа ли строка на UUID.
- **`ЗаменитьОдниСимволыДругими(ЗаменяемыеСимволы, Значение, СимволыЗамены)`** — посимвольная замена.
- **`СтрокаВЧисло(Значение)`** / **`СтрокаВДату(Значение, ЧастьДаты)`** — безопасное преобразование без исключений (возвращают `Неопределено`/пустую дату).
  🚲 `Попытка Число(Строка) Исключение …`.
- **`ИзвлечьТекстИзHTML(ИсходныйТекст)`** — текст без HTML-тегов.
  🚲 Свой вырезатель тегов регулярками.
- **`ПреобразоватьЧислоВРимскуюНотацию(Число)`** / **`ПреобразоватьЧислоВАрабскуюНотацию(Строка)`**.
- **`СтрокаСЧисломДляЛюбогоЯзыка(Шаблон, Число, Вид, ФорматнаяСтрока)`** — число + форма слова («1 минута / 2 минуты / 5 минут»).
  🚲 Свой выбор формы множественного числа. ⚠ устар.: `ФормаМножественногоЧисла`, `ЧислоЦифрамиПредметИсчисленияПрописью`.

### `СтроковыеФункции` (сервер) / `СтроковыеФункцииКлиент` (клиент)
- **`ФорматированнаяСтрока(Шаблон, Параметр1 … Параметр5)`** — форматированная строка с тегами стиля/картинками/ссылками.
  🚲 Ручная сборка `ФорматированнаяСтрока` через `Новый ФорматированныйДокумент`. ⚠ устар.: одноимённая в `СтроковыеФункцииКлиентСервер`.
- **`СтрокаЛатиницей(Значение)`** — транслит.
  🚲 Своя таблица транслитерации.
- **`ПредставлениеПериодаВТексте(ДатаНачала, ДатаОкончания, ФорматнаяСтрока, СЗаглавной)`** — «с … по …» строкой.

## Файловая система — `ФайловаяСистема` (сервер) / `ФайловаяСистемаКлиент` (клиент)

- **`ФайловаяСистема.СоздатьВременныйКаталог(Расширение = "")`** + **`УдалитьВременныйКаталог(Путь)`** / **`УдалитьВременныйФайл(Путь)`** — временные файлы/каталоги с корректной уборкой.
  🚲 `ПолучитьИмяВременногоФайла()` + `СоздатьКаталог` + ручное удаление в `Попытке`. ⚠ устар.: `ОбщегоНазначения.СоздатьВременныйКаталог/УдалитьВременныйКаталог`.
- **`ФайловаяСистема.УникальноеИмяФайла(ИмяФайла)`** (есть и на клиенте) — уникальное имя в каталоге («файл (2).txt»).
  🚲 Свой цикл с проверкой существования и инкрементом.
- **`ФайловаяСистема.ОбщийКаталогВременныхФайлов(ВложенныйКаталог)`** — общий сетевой каталог временных файлов (для клиент-сервера).
- **`ФайловаяСистема.ЗапуститьПрограмму(КомандаЗапуска, ПараметрыЗапускаПрограммы)`** + **`ПараметрыЗапускаПрограммы()`** (есть и на клиенте) — запуск внешней программы/команды ОС.
  🚲 `Новый COMОбъект("WScript.Shell")`; устаревший `ЗапуститьПриложение`. ⚠ устар.: `ОбщегоНазначенияКлиентСервер.ЗапуститьПрограмму`.

### `ФайловаяСистемаКлиент` (клиент) — работа с файлами пользователя
- **`ЗагрузитьФайл(ОбработчикЗавершения, ПараметрыЗагрузки, ...)`** / **`ЗагрузитьФайлы(...)`** + **`ПараметрыЗагрузкиФайла()`** — выбор файла и помещение во временное хранилище.
  🚲 Ручная связка `НачатьПомещениеФайла`/`НачатьПомещениеФайлов` с диалогом.
- **`СохранитьФайл(ОбработчикЗавершения, РасположениеФайла, ...)`** / **`СохранитьФайлы(...)`** + конструкторы параметров — получить и сохранить в ФС пользователя.
- **`ОткрытьФайл(РасположениеФайла, ...)`** + **`ПараметрыОткрытияФайла()`** — открыть файл во внешней программе.
- **`ОткрытьПроводник(ПутьККаталогуИлиФайлу)`** / **`ОткрытьНавигационнуюСсылку(Ссылка, Оповещение)`** — проводник / навигационная ссылка.
  🚲 ⚠ устар.-аналоги в `ОбщегоНазначенияКлиент`.
- **`ВыбратьКаталог(ОбработчикЗавершения, Заголовок, Каталог)`** / **`ПоказатьДиалогВыбора(...)`** — диалоги.
- **`ПодключитьРасширениеДляРаботы1СПредприятия(...)`** — расширение работы с файлами в веб-клиенте.
  🚲 ⚠ устар.: `ПодключитьРасширениеДляРаботыСФайлами`, аналоги в `ОбщегоНазначенияКлиент`.

## Присоединённые файлы — `РаботаСФайлами` (сервер) / `РаботаСФайламиКлиент`

Подсистема «Работа с файлами» (справочники файлов, версии, тома). Нужна при
прикреплении файлов к объектам.

- **`РаботаСФайлами.ДвоичныеДанныеФайла(ПрисоединенныйФайл, ВызыватьИсключение)`** / **`ДвоичныеДанныеФайлов(...)`** — получить двоичные данные файла.
  🚲 Ручное чтение из тома/хранилища значения.
- **`РаботаСФайлами.ДанныеФайла(ПрисоединенныйФайл, ...)`** — сведения о файле (структура).
- **`РаботаСФайлами.ДобавитьФайл(ПараметрыФайла, АдресФайлаВоВременномХранилище, ...)`** + **`ПараметрыДобавленияФайла(...)`** — создать присоединённый файл.
- **`РаботаСФайлами.ДобавитьФайлСДиска(ВладелецФайлов, ПутьКФайлуНаДиске)`** — добавить из ФС. ⚠ устар.: `СоздатьФайлНаОсновеФайлаНаДиске`.
- **`РаботаСФайлами.ОбновитьФайл(ПрисоединенныйФайл, ИнформацияОФайле)`** — обновить данные/текст/дату.
- **`РаботаСФайлами.СкопироватьПрисоединенныеФайлы(Источник, Получатель)`** — копировать все файлы объекта.
- **`РаботаСФайлами.ПриСозданииНаСервере/ПриЗаписиНаСервере(...)`** — встраивание полей файлов в форму (обработчики).
- **`РаботаСФайламиКлиент.ОткрытьФайл(ДанныеФайла, ДляРедактирования)`** / **`ДобавитьФайлы(...)`** / **`СохранитьФайлКак(...)`** — интерактивные операции.

## Журнал регистрации — `ЖурналРегистрации` (сервер) / `ЖурналРегистрацииКлиент`

- **`ЖурналРегистрации.ЗаписатьСобытияВЖурналРегистрации(СобытияДляЖурналаРегистрации)`** — **пакетная** запись набора событий одним вызовом.
  🚲 `ЗаписьЖурналаРегистрации(...)` в цикле по каждой записи (медленно).
- **`ЖурналРегистрацииКлиент.ДобавитьСообщениеДляЖурналаРегистрации(ИмяСобытия, Уровень, Комментарий, ...)`** + **`ЗаписатьСобытияВЖурналРегистрации()`** — накопить сообщения на клиенте и записать пачкой (один серверный вызов).
  🚲 Отдельный серверный вызов на каждую клиентскую запись в журнал.
- **`ЖурналРегистрацииКлиент.ОткрытьЖурналРегистрации(Отбор, Владелец)`** — открыть журнал с отбором.

## Пользователи — `Пользователи` (сервер) / `ПользователиКлиент`

- **`ТекущийПользователь()`** / **`АвторизованныйПользователь()`** (есть и на клиенте) — текущий пользователь (второй учитывает внешних).
  🚲 `Пользователи.НайтиПоИмени(ИмяПользователя())`; свой поиск по справочнику.
- **`ЭтоПолноправныйПользователь(Пользователь, ПроверятьАдминистрирование, ...)`** (есть и на клиенте) — полноправный ли.
  🚲 `РольДоступна("ПолныеПрава")`; проверка `ПривилегированныйРежим()`.
- **`РолиДоступны(ИменаРолей, Пользователь, ...)`** — доступна ли хоть одна из ролей (или полноправность).
  🚲 Несколько `РольДоступна(...)` через `ИЛИ`.
- **`ЭтоСеансВнешнегоПользователя()`** (есть и на клиенте) — вход внешнего пользователя.
- **`СвойстваПользователяИБ(ИмяИлиИдентификатор)`** / **`УстановитьСвойстваПользователяИБ(...)`** / **`НовоеОписаниеПользователяИБ(...)`** — свойства пользователя ИБ структурой.
  🚲 Прямая работа с `ПользователиИнформационнойБазы` и ручной сбор свойств.
- **`НайтиПоИмени(ИмяДляВхода)`** / **`НайтиПоИдентификатору(Идентификатор)`** / **`НайтиПоСсылке(Пользователь)`** — связь справочника и пользователя ИБ.
- **`СоздатьПароль(СвойстваПароля, ...)`** + **`СвойстваПароля()`** — генерация пароля по правилам сложности.
  🚲 Свой генератор случайного пароля.
- **`ГруппаВсеПользователи()`**, **`СсылкаНеуказанногоПользователя(...)`**, **`ПолноеИмяНеуказанногоПользователя()`** — стандартные предопределённые значения.

> ⚠ устар.: весь `ПользователиКлиентСервер` (`ТекущийПользователь`,
> `АвторизованныйПользователь` и т.д.) → `Пользователи`/`ПользователиКлиент`.

## Длительные операции — `ДлительныеОперации` (сервер) / `ДлительныеОперацииКлиент`

- **`ДлительныеОперации.ВыполнитьФункцию(ПараметрыВыполнения, ИмяФункции, Пар1…Пар7)`** / **`ВыполнитьПроцедуру(...)`** + **`ПараметрыВыполненияФункции(ИдентификаторФормы)`** / **`ПараметрыВыполненияПроцедуры()`** — запуск в фоновом задании.
  🚲 Прямой `ФоновыеЗадания.Выполнить(...)` с самодельным опросом состояния.
- **`ДлительныеОперации.ВыполнитьФункциюВНесколькоПотоков(...)`** / **`ВыполнитьПроцедуруВНесколькоПотоков(...)`** — многопоточное выполнение.
- **`ДлительныеОперации.СообщитьПрогресс(Процент, Текст, ...)`** / **`ПрочитатьПрогресс(Идентификатор)`** — прогресс операции.
- **`ДлительныеОперации.ЗаданиеВыполнено(Идентификатор, ...)`** / **`ОтменитьВыполнениеЗадания(Идентификатор)`** / **`СообщенияПользователю(...)`** — контроль задания.
- **`ДлительныеОперацииКлиент.ОжидатьЗавершение(ДлительнаяОперация, ОповещениеОЗавершении, ПараметрыОжидания)`** + **`ПараметрыОжидания(ФормаВладелец)`** — ожидание с окном прогресса.
  🚲 Свой `ПодключитьОбработчикОжидания` с опросом фона.

> ⚠ устар.: `ВыполнитьВФоне` → `ВыполнитьФункцию`/`ВыполнитьПроцедуру`;
> `ДлительныеОперацииКлиент.ОткрытьФормуДлительнойОперации` и
> `ИнициализироватьПараметрыОбработчикаОжидания` → `ОжидатьЗавершение`.

## Даты запрета изменения — `ДатыЗапретаИзменения` (сервер)

- **`ИзменениеЗапрещено(ДанныеИлиПолноеИмя, ИдентификаторДанных, ...)`** — запрещено ли изменение данных датой запрета.
  🚲 Свой расчёт и сравнение с «датой запрета» из настроек.
- **`НайденЗапретИзмененияДанных(ДанныеДляПроверки, ...)`** + **`ШаблонДанныхДляПроверки()`** + **`ПараметрыСообщенияОЗапрете()`** — проверка по таблице дат/разделов/объектов.
- **`ПроверитьДатыЗапретаЗагрузкиДанных(Данные, Узел, Отказ, ...)`** — проверка при загрузке из узла обмена.
- **`ОтключитьПроверкуДатЗапрета(Отключить)`** / **`ПроверкаДатЗапретаОтключена()`** — временно отключить проверку (пакетная обработка).
- Обработчики подписок: `ПроверитьДатуЗапретаИзмененияПередЗаписью*` — подключать как обработчики, не переписывать.

## Контактная информация — `УправлениеКонтактнойИнформацией` (сервер) / `*Клиент` / `*КлиентСервер`

Подсистема «Контактная информация».

- **`УправлениеКонтактнойИнформацией.КонтактнаяИнформацияОбъекта(СсылкаИлиОбъект, ВидИлиТип, Дата, ТолькоПредставление)`** / **`КонтактнаяИнформацияОбъектов(...)`** / **`КонтактнаяИнформация(Источник, Отбор)`** — получить КИ объекта(ов).
  🚲 Свой запрос к табличной части КонтактнаяИнформация.
- **`ПредставлениеКонтактнойИнформацииОбъекта(СсылкаИлиОбъект, Вид, Разделитель, ...)`** — представление КИ строкой.
- **`ДобавитьКонтактнуюИнформацию(СсылкаИлиОбъект, ЗначениеИлиПредставление, Вид, ...)`** / **`УстановитьКонтактнуюИнформациюОбъекта(СсылкаИлиОбъект, КИ, Замещать)`** — запись КИ.
- **`СведенияОбАдресе(Адрес, ...)`** / **`СведенияОбАдресах(Адреса, ...)`** — разбор адреса на поля (город, улица, индекс…).
  🚲 Свой парсер адресной строки.
- **`ПредставлениеАдреса(Адрес, ПараметрыПредставленияАдреса)`** + **`НовыеПараметрыПредставленияАдреса()`** — форматированный адрес.
- **`СведенияОТелефоне(КИ)`** / **`НомерТелефонаКонтактнойИнформации(КИ)`** — разбор телефона.
- **`*КлиентСервер.СформироватьПредставлениеТелефона(КодСтраны, КодГорода, Номер, Добавочный, Комментарий)`** — телефон строкой.
  🚲 Ручная склейка частей номера.
- **`ДанныеСтраныМира(КодСтраны, Наименование)`** / **`СтранаМираПоКодуИлиНаименованию(...)`** — справочник/классификатор стран.
- `*Клиент`: **`СоздатьЭлектронноеПисьмо(...)`** / **`СоздатьSMS(...)`** / **`ПозвонитьПоТелефону(Номер)`** / **`ПоказатьАдресНаКарте(Адрес, Сервис)`** — действия по КИ.

## Получение файлов из интернета — `ПолучениеФайловИзИнтернета` (сервер) / `*Клиент`

- **`СкачатьФайлНаСервере(URL, ПараметрыПолучения, ЗаписыватьОшибку)`** / **`СкачатьФайлВоВременноеХранилище(URL, ...)`** — скачать по http(s)/ftp.
  🚲 Свой `Новый HTTPСоединение` + `Получить` + разбор прокси/ошибок.
- **`*Клиент.СкачатьФайлНаКлиенте(URL, ...)`** — скачать на клиенте.
- **`НастройкиПроксиНаСервере()`** / **`НастройкиПроксиНаКлиенте()`** / **`ПолучитьПрокси(URLИлиПротокол)`** — настройки прокси.
  🚲 Ручное создание `Новый ИнтернетПрокси`.

## Банки и курсы валют

### `РаботаСБанками` (сервер)
- **`СведенияБИК(БИК, КоррСчет, ТолькоАктуальные)`** — данные банка из справочника БИК.
  🚲 Свой запрос к `КлассификаторБанков`/`Банки`. ⚠ устар.: `ПолучитьДанныеКлассификатора`.
- **`ПояснениеНедействительногоБанка(Банк)`** — причина недействительности.

### `РаботаСКурсамиВалют` (сервер)
- **`ПолучитьКурсВалюты(Валюта, ДатаКурса)`** — курс на дату.
  🚲 Свой запрос к регистру `КурсыВалют` со срезом последних.
- **`ПересчитатьВВалюту(Сумма, ИсходнаяВалюта, НоваяВалюта, Дата)`** — пересчёт между валютами.
  🚲 Ручной пересчёт по курсам и кратностям.
- **`СформироватьСуммуПрописью(СуммаЧислом, Валюта, БезДробной, КодЯзыка, ...)`** — сумма прописью.
  🚲 Свой алгоритм «сумма прописью».
- **`ОписаниеТипаДенежногоПоля(ДопустимыйЗнакПоля)`** — конструктор типа для денежных полей.
- **`ДобавитьВалютыПоКоду(КодыВалют)`** — добавить валюты из классификатора (начальное заполнение).
