# Задача #001 (#23): Учетная политика

## Цель
Добавить хранение Учетной политики в базу.

## План
Добавить справочник Организации , реквизиты: ИНН строка 12, КПП строка 9
Добавить перечисление МетодСписанияСебестоимости : ФИФО, ЛИФО
Добавить регистр сведений УчетнаяПолитика , измерение Организация, ресурс МетодСписанияСебестоимости, периодичность год
Добавить общий модуль РегламентированныйУчетПовтИсп , повторное использование возвращаемых значений на время сеанса
В общий модуль РегламентированныйУчетПовтИсп добавить функцию ДанныеУчетнойПолитики(Период, Организация) , будет возвращать структуру со всеми ресурсами РС УчетнаяПолитика по организации на дату.
Добавить видимую подсистему Оперативный учет.
Все объекты добавить в подсистему Оперативный учет.
Добавить роль Оперативный учет. 
Доступ на чтение и запись ко всем созданным объектам добавить в роль Оперативный учет (кроме перечисления, перечисления не добавляются в роли).

## Ограничения
Добавляем только перечисленные метаданные, больше никакие объекты не меняем
