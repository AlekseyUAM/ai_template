# Задача #004 (#26): Отчет Остатки товаров

## Цель
Добавить отчет Остатки товаров с данными о остатках в разрезе Партий.

## План
Добавить отчет ОстаткиТоваров, на СКД. Строится на дату, по организации.
Вид отчета:
Номенклатура        | Партия                | Количество    | Стоимость    | 
Куртка замшевая     |                       | 4             | 350          |
                    | Прих.накладная №1     | 2             | 250          |
                    | Прих.накладная №2     | 2             | 100          |
Портсигар           |                       | 6             | 65           |
                    | Прих.накладная №1     | 5             | 50           |
                    | Прих.накладная №3     | 1             | 15           |

В запросе используй границу.
Отчет добавить в подсистему Оперативный учет.
Доступ к отчету добавить в роль Оперативный учет.

## Ограничения
Добавляем только указанный отчет, больше никакие объекты не меняем
