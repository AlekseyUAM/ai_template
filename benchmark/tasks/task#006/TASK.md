# Задача #006 (#28): Отчет Продажи

## Цель
Сделать отчет Продажи

## План

Добавить отчет Продажи на СКД. Отчет строится за период, по организации: параметры Период и Организация. Собственную форму отчета не создавать — используется автоформа по СКД.

Источник данных — обороты регистра накопления Продажи за период с отбором по организации.

Колонки отчета (в указанном порядке):
- Номенклатура — группировка;
- Количество — суммарное количество за период;
- Себестоимость — суммарная стоимость списания за период;
- Продажа — суммарная сумма продажи за период;
- Прибыль — Продажа − Себестоимость.

Для услуг себестоимость не заполняется (равна 0), прибыль равна продаже.

Отчет добавить в подсистему Оперативный учет.
Доступ к отчету добавить в роль Оперативный учет.

## Ограничения
Добавляем отчет Продажи, меняем только его.
