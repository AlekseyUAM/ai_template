# Задача #002 (#24): Оперативный учет

## Цель
Реализовать оперативный учет товаров и услуг.

## План

### Учетная политика
В общий модуль РегламентированныйУчетПовтИсп добавить ДанныеУчетнойПолитики(Период, Организация): структура со всеми ресурсами РС УчетнаяПолитика на дату (СрезПоследних(Период, Организация = &Организация)).

### Приходная накладная
Проведение: запрос к ТЧ СписокНоменклатуры (отбор по Ссылка) с группировкой по номенклатуре, услуги отфильтровать. Писать Товары: Организация, Номенклатура, Партия = Ссылка, Количество, Стоимость = Сумма. Блокировка — не требуется.

### Расходная накладная
1. В ПередЗаписью при РежимЗаписи = Проведение, НЕ ЭтоНовый() и Проведен: получить дату по ссылке методом БСП, в ДополнительныеСвойства вставить ДатаДокументаСдвинутаВперед = ДатаПоСсылке < Дата.
2. В ОбработкаПроведения сначала получить и проверить политику; если метод не задан — сообщение и Отказ. 
3. Если ДатаДокументаСдвинутаВперед — очистить старые движения: Записывать = Истина для обоих регистров, Движения.Записать(), затем снова Записывать = Истина.
4. Блокировка: БлокировкаДанных на РегистрНакопления.Товары, Исключительный, ИсточникДанных = СписокНоменклатуры (без Выгрузить()), ИспользоватьИзИсточникаДанных("Номенклатура","Номенклатура"), УстановитьЗначение("Организация", Организация).
5. Один Запрос.Выполнить() в ОбработкаПроведения. Пакет:
   - ВТ1: запрос к ТЧ СписокНоменклатуры (отбор по Ссылка) с группировкой по номенклатуре + индексирование по Номенклатура.
   - ВТ2: Остатки товаров на границу исключая с отбором по ВТ1.Номенклатура и Организация = &Организация + индексирование по Номенклатура.
   - ВТ1 ЛЕВОЕ СОЕДИНЕНИЕ ВТ2 ПО Номенклатура; ЕСТЬNULL(ОстатокКоличество,0), ЕСТЬNULL(ОстатокСтоимость,0)
   - УПОРЯДОЧИТЬ ПО МоментВремениПартии ВОЗР (ФИФО) / УБЫВ (ЛИФО)
   - ИТОГИ ПО Номенклатура, постоянные поля (Количество, Сумма, Услуга) — МАКСИМУМ; остатки по партиям — СУММА
   - Два статических текста ФИФО/ЛИФО допустимы; в ОбработкаПроведения одно Запрос.Выполнить(), других Выполнить() нет.
6. Обход: ПоГруппировкам по номенклатуре, внутри Прямой по партиям. Для товара — списание по партиям с накоплением количества/стоимости; при нехватке — сообщение без привязки к строке и Отказ = Истина, проверить все позиции. Для услуги — только Продажи.
7. Продажи: Организация, Номенклатура; Количество из ТЧ, Сумма из ТЧ, Стоимость — стоимость списания (для услуги 0); движения положительные. Товары: Организация, Номенклатура, Партия, Количество, Стоимость списания.

## Ограничения
Изменяем объекты подсистемы Оперативный учет, больше никакие объекты не меняем.

## Тесты
Ровно 4 теста; каждый — своя организация «ООО Тест N», политика ФИФО с 01.01.2026. LIFO, отсутствие политики и нехватка остатка — вне объёма тестов.

| № | Документы (даты 2026) | Ожидаемые движения (Количество/Стоимость/Сумма) |
|---|---|---|
| 1 | 01.01 Приход Куртка замшевая 2×250; 02.01 Приход Куртка замшевая 2×100; 03.01 Расход Куртка замшевая 3×620 | Товары: Куртка замшевая 3/300; Продажи: Куртка замшевая 3/300/620 |
| 2 | 01.01 Приход Портсигар 5×50; 02.01 Приход Портсигар 1×15; 03.01 Расход Портсигар 3×50 + Доставка (Услуга=Истина) 1×100 | Товары: Портсигар 3/30; Продажи: Портсигар 3/30/50, Доставка 1/0/100; в Товары услуги нет |
| 3 | 01.01 Приход Портсигар 1×15; 02.01 Расход Портсигар 1×50; перепровести оба | Товары: Портсигар 1/15; Продажи: Портсигар 1/15/50; до и после совпадают |
| 4 | 01.01 Приход Портсигар 1×15; 02.01 Расход Портсигар 1×50 → изменить дату расхода на 03.01; перепровести | Товары: Портсигар 1/15; Продажи: Портсигар 1/15/50 |

Для Товары формат Количество/Стоимость, для Продажи — Количество/Стоимость/Сумма. Изоляция: каждый тест создаёт свои организацию, номенклатуру и документы; данные предыдущих тестов не используются.
