# Задача #007 (#29): Отчет Остатки товаров

## Цель
Сделать отчет Остатки товаров

## План

Добавить отчет Остатки товаров (ОстаткиТоваров) на СКД. Отчет строится на дату, по организации: параметры Период, Организация. Собственную форму отчета не создавать — используется автоформа по СКД.

Источник данных — остатки регистра накопления Товары на дату с отбором по организации. В запросе используй границу: остатки на конец выбранного дня, движения этого дня включаются (верхняя граница — КОНЕЦПЕРИОДА(&Период, ДЕНЬ) + 1 секунда).

Колонки отчета (в указанном порядке):
- Номенклатура — группировка;
- Партия — группировка внутри номенклатуры, представление документа-партии;
- Количество — остаток по партии;
- Стоимость — остаток стоимости по партии.

На уровне номенклатуры выводить итоги по количеству и стоимости, ниже — строки партий.

Вид отчета (пример на 01.01.2010):
- Куртка замшевая — итого: Количество 4, Стоимость 350.
  - Партия «Прих. Накладная №1»: Количество 2, Стоимость 250.
  - Партия «Прих. Накладная №2»: Количество 2, Стоимость 100.
- Портсигар — итого: Количество 6, Стоимость 65.
  - Партия «Прих. Накладная №1»: Количество 5, Стоимость 50.
  - Партия «Прих. Накладная №3»: Количество 1, Стоимость 15.

Отчет добавить в подсистему Оперативный учет.
Доступ к отчету добавить в роль Оперативный учет.

## Ограничения
Добавляем отчет Остатки товаров, меняем только его.
