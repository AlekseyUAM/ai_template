# Задача #004 (#26): Расходная накладная

## Цель
Добавить обработку события ПередЗаписью и обработку проведения документа Расходная накладная.

## План

### ПередЗаписью
При РежимЗаписи = Проведение, НЕ ЭтоНовый() и Проведен: получить дату по ссылке методом БСП, в ДополнительныеСвойства вставить ДатаДокументаСдвинутаВперед = ДатаПоСсылке < Дата.

### ОбработкаПроведения

1. Получить данные регистра сведений УчетнаяПолитика - МетодСписанияСебестоимости; если метод не задан — сообщение и Отказ. 
2. Если ДополнительныеСвойства.ДатаДокументаСдвинутаВперед — очистить старые движения: Записывать = Истина для обоих регистров, Движения.Записать(), затем снова Записывать = Истина.
3. Блокировка: БлокировкаДанных на РегистрНакопления.Товары, Исключительный, ИсточникДанных = СписокНоменклатуры (без Выгрузить()), ИспользоватьИзИсточникаДанных("Номенклатура","Номенклатура"), УстановитьЗначение("Организация", Организация).
4. Один Запрос.Выполнить() в ОбработкаПроведения. Пакет:
   - ВТ1: запрос к ТЧ СписокНоменклатуры (отбор по Ссылка) с группировкой по номенклатуре + индексирование по Номенклатура.
   - ВТ2: Остатки товаров на границу исключая с отбором по ВТ1.Номенклатура и Организация = &Организация + индексирование по Номенклатура.
   - ВТ1 ЛЕВОЕ СОЕДИНЕНИЕ ВТ2 ПО Номенклатура;
   - УПОРЯДОЧИТЬ ПО МоментВремениПартии ВОЗР (ФИФО) / УБЫВ (ЛИФО)
   - ИТОГИ ПО Номенклатура, постоянные поля (Количество, Сумма, Услуга) — МАКСИМУМ.
   - Направление сортировки подставляем в запрос через СтрЗаменить; в ОбработкаПроведения один Запрос.Выполнить(), других Выполнить() нет.
5. Обход: ПоГруппировкам по номенклатуре, внутри Прямой по партиям. Для товара — списание по партиям с накоплением количества/стоимости; при нехватке — сообщение без привязки к строке и Отказ = Истина, проверить все позиции. Для услуги — только Продажи.
6. Продажи: Организация, Номенклатура; Количество из ТЧ, Сумма из ТЧ, Стоимость — стоимость списания (для услуги 0); движения положительные. Товары: Организация, Номенклатура, Партия, Количество, Стоимость списания.

## Ограничения
Область изменений: документ РасходнаяНакладная и связанные объекты подсистемы ОперативныйУчет.

### Тест 1. ФИФО: списание из двух партий

Организация «ООО Тест 1». Номенклатура: «Куртка замшевая» (товар). Метод списания — ФИФО с 01.01.2026.

Документы:
- 01.01.2026 — Приходная накладная: Куртка замшевая, 2 × 250 = 500.
- 02.01.2026 — Приходная накладная: Куртка замшевая, 2 × 100 = 200.
- 03.01.2026 — Расходная накладная: Куртка замшевая, 3 × 300 = 900.

Ожидаемые движения документа 3 (ФИФО: 2 шт. из партии документа 1, 1 шт. из партии документа 2), период 03.01.2026:
- Товары, ВидДвижения = Расход: Куртка замшевая, партия — документ 1: Количество 2, Стоимость 500.
- Товары, ВидДвижения = Расход: Куртка замшевая, партия — документ 2: Количество 1, Стоимость 100.
- Продажи: Куртка замшевая: Количество 3, Стоимость 600, Сумма 900.

Итого по документу 3: Товары — Количество 3, Стоимость 600; Продажи — Количество 3, Стоимость 600, Сумма 900.
